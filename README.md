# Видимость бренда в ответах ИИ

Раз в неделю инструмент задаёт шести ИИ-движкам вопросы ваших покупателей и считает, как часто называют ваш бренд и конкурентов. Движки: ChatGPT, Gemini, Google AI Mode, Google AI Overviews, Perplexity и Claude. Итог публикуется закрытой страницей-дашбордом, где замеры сравниваются между собой.

Что видно на странице:
- **упоминания**: доля ответов с вашим брендом, погрешность, место среди названных компаний, доля голоса;
- **тон**: лучший выбор, рекомендует, просто упоминает, с оговорками, не советует — с цитатой из ответа;
- **конкуренты**: кого называют вместо вас, по каждому движку;
- **источники**: на какие сайты и страницы ссылается ИИ, где среди них ваш сайт и ваши публикации;
- **запросы ИИ**: что движок сам искал, отвечая на вопрос;
- **«Что делать»**: шесть списков страниц, вопросов и площадок, с которыми можно работать сразу;
- **оценка бренда**: несколько моделей ставят вашей компании и конкурентам оценки от 0 до 5 по вашим критериям.

Любое число на странице нажимается и открывает ответы, из которых оно сложилось.

Посмотреть страницу можно сразу, без аккаунта и затрат. На выдуманном бренде «Тасколёт» (все данные сочинены):

```
AV_PROJECT=project.example.json python3 scripts/flymy_site.py --run 2026-11-23 --dry out/demo --data examples/demo
cd out/demo && python3 -m http.server 8000     # открыть http://localhost:8000
```

## Как начать

Отдайте эту папку своему Claude Code или Codex и попросите: «Настрой замер видимости по инструкции из AGENTS.md». Агент спросит про бренд, конкурентов и вопросы, заполнит настройки, создаст приложение в FlyMyAI, сделает пробный замер на 5 вопросах и запустит полный. Перед каждым платным шагом он называет цену и ждёт вашего «да».

Что понадобится:
- **Аккаунт FlyMyAI** (app.flymy.ai) с балансом и API-ключ. Ключ кладёте сами в файл `config/flymyai.env` одной строкой `FLYMYAI_API_KEY=…`. Агенту файл ключа не показывайте.
- **Ключ OpenRouter** — по желанию: нужен только для оценки бренда у Claude. Строка `OPENROUTER_API_KEY=…` в `config/openrouter.env`. Без ключа этот шаг пропускается.
- **Python 3.11 или новее.** Сторонние библиотеки не нужны.

Каждая команда разворачивает инструмент в своём аккаунте FlyMyAI и платит со своего баланса.

## Сколько стоит

Цены проверены в ноябре 2026.

| Шаг | Цена |
|---|---|
| Первичная настройка (`setup.py`): приложение, агент, страница | бесплатно |
| Съём одного вопроса во всех шести движках | ≈ $0,08 (Claude ≈ $0,05, Perplexity ≈ $0,015, остальные по $0,004) |
| Разбор ответов (компании и тон) | ≈ $0,01 на вопрос |
| Пробный замер: 5 вопросов, без оценки бренда | ≈ $0,5 |
| Недельный замер на 100 вопросах | ≈ $9 |
| Оценка бренда, один сценарий: GPT и Gemini, с поиском и без, по 2 запуска | ≈ $2,6 |
| То же у Claude через OpenRouter | ≈ $3,2 (списывается с OpenRouter) |
| Публикация страницы | бесплатно |

Оценку для ваших настроек печатает `python3 scripts/setup.py`. Он ничего не создаёт и не тратит.

Сборщик в FlyMyAI иногда выполняет код дважды, и тогда платные вызовы удваиваются. Держите на балансе запас.

## Устройство

| Файл | Что делает |
|---|---|
| `project.json` | Все настройки проекта: бренд, конкуренты, свои сайты и публикации, вопросы, темы, оценка бренда, ID в FlyMyAI. Образец — `project.example.json`. Сам файл в git не попадает |
| `scripts/setup.py` | Первичная настройка: проверяет настройки, создаёт приложение (сборщик и хранилище), агента оценки бренда и страницу; ID пишет в `project.json` |
| `scripts/week.sh` | Весь недельный замер одной командой |
| `scripts/flymy_measure.py` + `flymy_app/collect_batch.py` | Съём: вопросы режутся на части, облачный сборщик ходит в движки через DataForSEO, упавшее добирается |
| `scripts/flymy_entities.py` | Разбор ответов дешёвой моделью: какие компании названы и с каким тоном назван ваш бренд |
| `scripts/enrich.py` | Раскрывает редиректы Google, достаёт контекст цитат, открывает ваши процитированные страницы и проверяет, где на них стоит бренд |
| `scripts/flymy_brand.py`, `scripts/brand_openrouter.py` | Оценка бренда: GPT и Gemini через агента FlyMyAI, Claude через OpenRouter |
| `scripts/flymy_site.py` + `flymy_app/finalize.py` | Сводка и публикация страницы; `--dry папка` собирает страницу локально и ничего не пишет в FlyMyAI |
| `flymy_app/site/` | Страница |

Данные замеров хранятся в хранилище приложения FlyMyAI: `runs/`, `raw/`, `brand/`, `summary/`.

## Настройки (`project.json`)

- **`brand`** — имя бренда (так оно будет подписано на странице), основной сайт, шаблоны написания.
- **`patterns`** — регулярные выражения Python. Свой бренд ищется без учёта регистра, конкуренты — с учётом. Если название — обычное слово (Monday, Notion, Linear), шаблон должен отсекать обычное употребление: `\bMonday\.com\b` вместо `monday`. Иначе упоминаний будет больше, чем на деле. Из названия шаблоны автоматически не строятся.
- **`own_sites`** — другие ваши сайты, кроме основного. Можно оставить пустым: тогда строки и фильтры «Другие наши сайты» на странице не показываются.
- **`publications`** — файл со ссылками на ваши статьи и посты на чужих площадках. Формат — в `examples/publications.txt`: адрес, `link адрес` для купленной статьи, `blog хост` для блога, который весь ваш. Пустые виды на странице скрываются.
- **`competitors`** — имя, домен, шаблоны. Их же модели оценивают в «Оценке бренда».
- **`questions`** — файл вопросов: `id`, `text` (до 500 знаков), `lang` (`ru` или `en`), `tags` (этап покупателя: ключ из `stages`). Страна берётся из `loc_code` вопроса, а если его нет — из `locations` по языку. Код страны — по справочнику DataForSEO, например 2840 — США.
- **`topics`** — темы вопросов: ключ, подпись и регулярное выражение по тексту вопроса; подходит первая совпавшая, иначе тема по умолчанию. Считаются при сводке, поэтому их можно менять без пересъёма.
- **`analysis`** — для модели-разборщика:
  - `company_kinds` — какие компании считать (ваша отрасль);
  - `not_companies` — что компаниями не считать;
  - `suffixes` — хвосты названий, которые склеиваются: «Acme Software» = «Acme».
- **`brand_score`**:
  - `scenarios` — ситуации покупателя: файл с текстом; список компаний и критерии скрипт допишет сам; в `exclude` — кого не оценивать в этом сценарии;
  - `criteria` — критерии с подписью и пояснением для модели. Обязателен `overall`: по нему строится место и итоговая таблица;
  - `models`, `openrouter`, `runs` — какие модели и сколько запусков.
- **`site`** — заголовок страницы, кто задаёт вопросы (для вкладки «Как считаем»), строка про страны.
- **`flymy`** — имя приложения `логин/имя` (логин — ваш в FlyMyAI). Остальные поля заполняет `setup.py`.

## Ограничения и особенности платформы

- **Языки вопросов — только русский и английский.** Фильтры страницы, приписка к оценке бренда и определение языка запросов рассчитаны на эти два.
- **Не больше трёх долгих запусков на аккаунт одновременно.** На «capacity is busy» скрипты сами ждут и повторяют.
- **Если съём упал, его не перезапускают.** При «часть не завершена» `week.sh` останавливается. Причину нужно смотреть в результате запуска (`get_run`), досъём — флагом `--only-chunks`. Автоматические повторы однажды стоили около $19.
- **Дневной лимит бюджета проекта** в FlyMyAI ниже стоимости замера обрывает съём на середине. Шаблон приложения лимит не ставит.
- **Баланс FlyMyAI обновляется с задержкой.** Расход шага по разнице баланса не считается: смотрите `list_execution_prices`.
- **Запись в хранилище** — не больше 256 КБ за вызов, считая с экранированием (русская буква — 6 байт). Подписанные ссылки в тексте платформа не принимает. Обе вещи учтены в сборщике.
- **AI Overviews отдаёт источники редиректами Google.** Их раскрывает `enrich.py`, без него ваши источники недосчитываются.
- **Claude на русском вопросе без просьбы поискать** оценивает компании по памяти. В режиме «с поиском» к вопросу дописывается просьба искать.
- **Страница закрыта:** её видит владелец аккаунта FlyMyAI. Доступ коллегам даётся в FlyMyAI (`invite_to_site`).
