# Инструкция для агента: настроить и вести замер видимости

Ты настраиваешь замер видимости бренда в ответах ИИ для владельца этой папки. Что делает инструмент, сколько стоит и как устроены настройки — в `README.md`; прочитай его до начала работы. С владельцем говори на его языке, коротко и без жаргона.

## Правила, которые не нарушать

1. **Платные шаги — только после «да» владельца.** Перед каждым ты называешь цену: пробный замер, полный замер, оценку бренда. Бесплатные шаги делаешь сам: настройки, `setup.py` без `--apply`, сборку `--dry`.
2. **Файлы ключей не открывай и не выводи:** `config/*.env`. Ключ владелец кладёт сам. Есть ли ключ, ты узнаёшь по выводу `setup.py`.
3. **Упавший съём не перезапускай.** Если `week.sh` остановился с «СТОП: съём прошёл не целиком», не запускай его снова. Прочитай результат запуска: `python3 scripts/flymy.py call get_run '{"execution_id":"…"}'`, ID есть в логе `out/logs/measure_<дата>.log`. Расскажи владельцу, что случилось, и досними только упавшие части флагом `--only-chunks` — с его согласия.
4. **Не ставь лимиты бюджета** проекта в FlyMyAI ниже стоимости замера: съём оборвётся на середине.
5. **Не меняй** код сборщика, форму вызовов движков и лимиты размеров и параллельности. Они подобраны под ограничения платформы, и ошибка в них стоит денег.

## Шаг 1. Расспросить владельца

Спрашивай по одному блоку, предлагай варианты, не заставляй писать регулярные выражения:

1. **Бренд:**
   - название, как его надо подписывать;
   - основной сайт;
   - как ещё пишут название: латиницей, кириллицей, с доменом.

   Если название — обычное слово, предупреди: без точных шаблонов будут ложные упоминания.
2. **Свои площадки:**
   - другие свои сайты;
   - свои статьи и посты на чужих площадках;
   - купленные статьи;
   - блоги, которые целиком свои.

   Всё необязательно.
3. **Конкуренты:** 5–30 компаний, с сайтами. Предложи список сам, если владелец затрудняется, и пусть он его поправит.
4. **Вопросы покупателей.**
   - Если у владельца их нет, предложи 30–100 штук: как покупатель спрашивает ИИ, когда ищет такой продукт. Подборки «лучшие…», «как сделать…», «чем заменить…», развёрнутые ситуации.
   - Языки — только русский и английский. Для каждого языка нужна страна (код DataForSEO, например 2840 — США).
   - Этап покупателя по каждому вопросу: ищет продукт / ищет способ решить задачу / разбирается в теме.
5. **Темы вопросов** для разреза на странице: 3–6 тем с ключевыми словами. Предложи сам по списку вопросов.
6. **Отрасль для разборщика:** какие компании считать (например, «таск-трекеры, CRM») и что компаниями не считать (методологии, форматы, платёжные системы — что уместно).
7. **Оценка бренда** — нужна ли.
   - Если да: 1–2 ситуации покупателя по 3–5 предложений (кто он, какая боль, что выбирает);
   - 3–6 критериев оценки плюс обязательный `overall`;
   - нужен ли Claude через OpenRouter (это отдельный ключ и ≈ $3 за сценарий).
8. **Логин в FlyMyAI** и как назвать приложение: `логин/ai-visibility-<бренд>` маленькими латинскими буквами.

## Шаг 2. Заполнить настройки

1. Скопируй `project.example.json` в `project.json` и замени всё на данные владельца. Пример на выдуманном бренде — образец формата, ничего из него не оставляй.
2. Вопросы положи в отдельный файл (например `config/questions.json`), сценарии оценки — в `config/score_<ключ>.txt`, публикации — в `config/publications.txt`. Пути пропиши в `project.json`. Папка `config/` в git не попадает.
3. Шаблоны: каждый проверь на 2–3 фразах, где название есть и где его нет, коротким `python3 -c "import re; …"`.

## Шаг 3. Проверка и создание в FlyMyAI

1. Попроси владельца положить ключ: строка `FLYMYAI_API_KEY=…` в файл `config/flymyai.env`. Он делает это сам.
2. `python3 scripts/setup.py` — бесплатно. Скрипт проверяет настройки и ключ и показывает:
   - аккаунт и баланс;
   - план приложения;
   - оценку стоимости замера.

   Ошибки в настройках исправь. План и цены покажи владельцу.
3. После его «да» — `python3 scripts/setup.py --apply`. Скрипт создаёт:
   - приложение (сборщик и хранилище);
   - агента оценки бренда;
   - страницу-заглушку.

   ID записываются в `project.json`. Создание бесплатно, агенты поднимаются 1–3 минуты. Повторный запуск безопасен.
4. Дай владельцу ссылку на страницу из вывода.

## Шаг 4. Пробный замер — стоп, спроси

Назови цену (≈ $0,5 за 5 вопросов без оценки бренда) и дождись «да». Потом:

```
LIMIT=5 BRAND=0 scripts/week.sh            # дата — сегодняшняя
```

Идёт 10–20 минут. Проверь:
- лог: нет «не завершена» и «после добора осталось»;
- страница опубликована;
- в ответах находится бренд, если движок его называл.

Открой пару ответов вместе с владельцем. Проверь, что шаблоны не ловят лишнего и не пропускают названий. Шаблоны и темы правь и пересобирай без новой оплаты: `python3 scripts/flymy_site.py --run <та же дата>`.

## Шаг 5. Полный замер — стоп, спроси

Назови цену из вывода `setup.py`: съём, разбор, оценка бренда. Проверь, что баланса хватает с запасом. После «да»:

```
scripts/week.sh                              # или BRAND=0 scripts/week.sh — без оценки бренда
```

Полный замер на 100 вопросах идёт около часа. Повторный запуск с той же датой продолжает с места остановки и уже снятое не оплачивает. Но если скрипт сам остановился с «СТОП», действуй по правилу 3.

## Дальше — раз в неделю

`scripts/week.sh` в тот же день недели. Сравнение с прошлым замером на странице включается само со второго замера.

Новые публикации владельца дописывай в файл публикаций до сводки. Сводку можно пересобрать бесплатно: `python3 scripts/flymy_site.py --run <дата>`.

## Когда остановиться и спросить

- Любой платный запуск, повтор после ошибки, досъём.
- Баланса FlyMyAI меньше стоимости замера с запасом в 30%.
- Скрипт остановился, упал или ведёт себя не так, как описано.
- Владелец просит то, чего здесь нет: другие движки, третий язык, расписание в FlyMyAI. Это правка кода, её решает владелец.
